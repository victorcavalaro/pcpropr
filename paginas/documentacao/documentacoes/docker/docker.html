Documentação Docker

📦 O que é Docker?

Docker é uma plataforma de código aberto que permite empacotar, distribuir e executar aplicações em containers de forma isolada e consistente em qualquer ambiente.

🧱 O que é um Container?

Um container é uma unidade leve que empacota o código da aplicação, suas bibliotecas e dependências para rodar de forma portátil e previsível.

⚙️ Como o Docker Funciona?

Funciona com imagens, que são moldes, e containers, que são instâncias dessas imagens. Tudo é definido em um Dockerfile, com comandos para montar o ambiente.

📥 Instalação

Baixe o Docker Desktop do site oficial. Após instalar, use o terminal para verificar com docker --version.

🚀 Criando um Container

Crie um projeto com Dockerfile, construa com docker build e execute com docker run.

📌 Comandos Essenciais

docker build, docker run, docker ps, docker stop, docker rm, docker rmi.

📄 Dockerfile

Arquivo que define instruções para construir a imagem da aplicação: imagem base, diretório, dependências, comandos e portas.

🧩 Docker Compose

Ferramenta para definir e rodar múltiplos containers com um arquivo docker-compose.yml. Ideal para apps com banco de dados e back-end separados.

☁️ Docker Hub

Repositório público onde você pode baixar ou publicar imagens Docker, como mysql, nginx, node, entre outras.

✅ Vantagens do Docker

Ambiente padronizado, leve, rápido, fácil de escalar, facilita o CI/CD e reduz erros entre dev e produção.

💼 Casos de Uso

Ambientes de desenvolvimento, microserviços, testes automatizados, integração contínua, deploy em nuvem, e mais.
