1. Fundamentos do TypeScript

TypeScript é uma linguagem desenvolvida pela Microsoft que atua como um superset (superconjunto) do JavaScript. O objetivo principal é adicionar tipagem estática ao código, permitindo que erros sejam detectados durante o desenvolvimento (tempo de compilação) e não apenas quando o usuário está usando o sistema (tempo de execução).

1.1 Superset do JavaScript

Imagine que o JavaScript é uma casa. O TypeScript é essa mesma casa, mas reformada com sistemas de segurança modernos. Todo código JavaScript válido é, tecnicamente, um código TypeScript válido. Você não perde o que já sabe; você apenas ganha novas ferramentas.


// JS Puro (Válido em TS)
function somar(a, b) {
    return a + b;
}

1.2 Tipagem Estática Opcional

A "mágica" do TypeScript. Enquanto no JS as variáveis podem mudar de tipo a qualquer momento (o que causa bugs), no TS definimos contratos claros.


// TypeScript
let nome: string = "João";
// nome = 10; // ❌ O compilador avisa imediatamente: "Type 'number' is not assignable to type 'string'"

1.3 Transpilação

Navegadores não leem TypeScript. Eles leem JavaScript. O processo de transformar TS em JS chama-se Transpilação. O arquivo final que vai para a produção é sempre .js, limpo e otimizado.

2. Tipos Primitivos

Os blocos de construção básicos da linguagem.

Tipo Descrição Exemplo
string Textos e caracteres. "Olá Mundo"
number Inteiros e flutuantes. 42, 10.5
boolean Verdadeiro ou Falso. true, false
void Vazio (geralmente para funções sem retorno). function log(): void {}
unknown Seguro. Exige verificação antes de usar. Uso em APIs externas.
any Perigoso. Aceita tudo. Evite. Legado ou testes rápidos.
never Nunca retorna (ex: erro ou loop infinito). throw new Error()

3. Tipos Avançados

Recursos que dão poder real ao TypeScript para modelar regras de negócio complexas.

3.1 Interfaces e Type Aliases

Usados para definir a forma de um objeto.


// Interface (Preferível para objetos e extensibilidade)
interface Usuario {
    id: number;
    nome: string;
    email?: string; // ? significa opcional
}

// Type Alias (Preferível para uniões e primitivos)
type ID = string | number;

const user: Usuario = { id: 1, nome: "Ana" };

3.2 Union Types (|) e Intersection Types (&)

Union permite que uma variável seja de um tipo OU de outro. Intersection combina múltiplos tipos em um só.


function printId(id: number | string) {
    console.log("Seu ID é: " + id);
}

type Trabalhador = { empresa: string };
type Pessoa = { nome: string };
type Funcionario = Pessoa & Trabalhador; // Tem nome E empresa

3.3 Generics (<T>)

Permitem criar componentes reutilizáveis que funcionam com vários tipos, mantendo a segurança.


// Uma função que devolve o que recebeu, mantendo o tipo
function identidade<T>(arg: T): T {
    return arg;
}

let saida1 = identidade<string>("meuString");
let saida2 = identidade<number>(100);

4. Orientação a Objetos

O TypeScript traz recursos de linguagens como Java e C# para o JavaScript.


class Animal {
    protected nome: string; // Acessível aqui e nas subclasses

    constructor(nome: string) {
        this.nome = nome;
    }

    public mover(distancia: number): void {
        console.log(`${this.nome} moveu-se ${distancia}m.`);
    }
}

class Cachorro extends Animal {
    latir() {
        console.log("Au! Au!");
    }
}

const dog = new Cachorro("Rex");
dog.latir();
dog.mover(10);

8. Boas Práticas (Best Practices)

Escrever código que funciona é fácil. Escrever código sustentável exige disciplina. Aqui estão as regras de ouro do TypeScript:

🚫 1. Evite o any a todo custo

Usar any desliga a checagem do TypeScript. É como dirigir sem cinto de segurança. Se não souber o tipo, use unknown.

✅ 2. Use Strict Mode

Mantenha "strict": true no seu tsconfig.json. Isso ativa verificações rigorosas de nulos e tipos implícitos.

⚡ 3. Use Interfaces para Contratos de API

Sempre que receber dados de um backend (JSON), crie uma Interface que represente esses dados. Isso garante que você não tente acessar propriedades que não existem.

🔒 4. Utilize Readonly

Se uma propriedade não deve ser alterada após a criação, use readonly para garantir imutabilidade.


interface Config {
    readonly apiEndpoint: string;
}

9. Tutorial Prático: CRUD com TypeScript e DOM

Abaixo, transformamos um exemplo clássico de JavaScript para TypeScript. Note o uso de Type Assertions (as HTMLInputElement) para dizer ao TS que elemento HTML estamos manipulando.

9.1 Estrutura HTML

<!-- HTML -->
<form id="aluno-form">
    <input type="text" id="nome" placeholder="Nome do aluno" required>
    <button type="submit">Adicionar Aluno</button>
</form>

<table>
    <thead>
        <tr>
            <th>Nome</th>
            <th>Ações</th>
        </tr>
    </thead>
    <tbody id="alunos-tabela">
        <!-- Dados renderizados via TS -->
    </tbody>
</table>

9.2 O Código TypeScript

Observe como definimos a interface Aluno e tipamos os elementos do DOM.


// 1. Definição do Tipo de Dados (Contrato)
interface Aluno {
    id: number;
    nome: string;
}

// 2. Seleção de Elementos com Type Casting
// O 'as HTMLFormElement' garante que temos acesso a métodos de formulário
const formulario = document.getElementById("aluno-form") as HTMLFormElement;
const tabela = document.getElementById("alunos-tabela") as HTMLTableSectionElement;
const nomeInput = document.getElementById("nome") as HTMLInputElement;

// 3. Estado da Aplicação
let alunos: Aluno[] = []; 

// 4. Função para Adicionar
formulario.addEventListener("submit", (evento: Event) => {
    evento.preventDefault(); // Evita recarregamento da página

    const nomeAluno = nomeInput.value.trim();

    if (nomeAluno) {
        const novoAluno: Aluno = {
            id: Date.now(),
            nome: nomeAluno
        };
        
        alunos.push(novoAluno);
        atualizarTabela();
        nomeInput.value = ""; // Limpa o input
        nomeInput.focus();
    }
});

// 5. Função de Renderização
function atualizarTabela(): void {
    tabela.innerHTML = ""; // Limpa a tabela

    alunos.forEach((aluno) => {
        const linha = document.createElement("tr");

        // Criando células manualmente ou via Template String
        linha.innerHTML = `
            <td>${aluno.nome}</td>
            <td>
                <button class="btn-editar" data-id="${aluno.id}">Editar</button>
                <button class="btn-excluir" data-id="${aluno.id}" style="background-color: #dc3545;">Excluir</button>
            </td>
        `;
        tabela.appendChild(linha);
    });

    // Reatribuir eventos aos novos botões (necessário pois o HTML foi recriado)
    adicionarEventosBotoes();
}

// 6. Manipulação de Eventos Dinâmicos
function adicionarEventosBotoes(): void {
    const btnsEditar = document.querySelectorAll(".btn-editar");
    const btnsExcluir = document.querySelectorAll(".btn-excluir");

    btnsEditar.forEach(btn => {
        btn.addEventListener("click", () => {
            const id = Number((btn as HTMLButtonElement).getAttribute("data-id"));
            editarAluno(id);
        });
    });

    btnsExcluir.forEach(btn => {
        btn.addEventListener("click", () => {
            const id = Number((btn as HTMLButtonElement).getAttribute("data-id"));
            deletarAluno(id);
        });
    });
}

// 7. Ações de Edição e Exclusão
function editarAluno(id: number): void {
    const aluno = alunos.find(a => a.id === id);

    if (aluno) {
        const novoNome = prompt("Digite o novo nome:", aluno.nome);
        if (novoNome && novoNome.trim() !== "") {
            aluno.nome = novoNome.trim();
            atualizarTabela();
        }
    }
}

function deletarAluno(id: number): void {
    // Confirmação simples
    if(confirm("Tem certeza que deseja excluir?")) {
        alunos = alunos.filter(a => a.id !== id);
        atualizarTabela();
    }
}
